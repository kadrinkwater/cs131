- Iterate through all positional parameters

mvg() function
https://gist.github.com/zachbrowne/8bc414c9f30192067831fafebd14255c#file-the-ultimate-bad-ass-bashrc-file-L311

- Accepts two positional parameters, a file and a destination
- If the destination is a directory: mv the file to the destination and also cd to the destination
- (I didn't realize you could use && this way, just to chain two commands together outside of a test expression. I wonder why the author did this. Something to do with the exit status of mvg?)
- If the destination isn't a directory, just mv the file there and don't cd anywhere.
- (you don't need to use mvg() in this case, but you might use it out of habit, so it's good for it to handle both cases)

Function with if statement:
https://github.com/kadrinkwater/cs131/blob/f58f7f01f37e43c0fc40573941b5c80bd5e17cef/ws4/.bashrc#L14
First, check if the string $1 is of nonzero length.
If so, cd to $1 and ls.
If not, cd home and ls.

(I thought about also checking if $1 exists and is a directory, and returning an error if not. But I realized that I don't know how to return an error exit status... and I was about to look that up... when I realized that the built-in cd will just do that for you if you try to cd somewhere that doesn't exist. Simpler!)
