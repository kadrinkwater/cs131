## Part B
B1: I am user ishigaki-cs1. uid=1034, gid=1034, and I am in the groups ishigaki-cs1, video, docker, and render. UID = User ID, GID = Group ID = the ID number for the single-user group that each user is in.
B2: fruits.txt has the permission string "-rw-rw-r--". That means: it is not a file, I (the owner) can read and write but not execute, the group can rw but not x, and any user can only read.
B3: The umask is 002. When a new file is made, it subtracts 002 from 666 to get 664 (rw-rw-r--).
B4: chmod 000 secret.txt ; chmod u+rw secret.txt 
B5: chmod 640 fruits.txt
